Privacy

Meridrift uploader is a personal tool maintained by Tim Vermeulen for his own YouTube channels.

The local metrics dashboard reads channel and video metadata, public and private video inventories, engagement counts and YouTube Analytics reports. It uses this data only to show the owner his channel performance. The uploader uses separately authorized access to send the owner's selected videos and metadata to YouTube.

Metrics and video metadata are stored in a local database on the owner's computer. The dashboard stores its OAuth refresh tokens in macOS Keychain. Google credentials are used only to communicate with Google's APIs. This information website receives no channel data or OAuth tokens.

Google user data is not sold, used for advertising, shared with other people or used to train AI models. This tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

The owner can revoke authorization through Google Account connections and delete locally stored data and credentials at any time. Local data is retained until deleted by the owner. This informational website is hosted by GitHub Pages, which may process ordinary website request logs under GitHub's privacy statement.
